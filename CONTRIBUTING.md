# Contributing

1. Fork the repo and create your feature branch: `git checkout -b feature/amazing`  
2. Install deps: `pip install -r requirements.txt`  
3. Run tests: `pytest` and lint: `flake8`  
4. Commit and push: `git commit -m 'feat: add amazing feature'`  
5. Open a Pull Request.

Please keep PRs small and focused. Add or update tests for any new code.
